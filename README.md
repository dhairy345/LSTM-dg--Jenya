# Experiments on LSTM-Based Text Generation

This README summarizes the experiments conducted to evaluate how different architectural and decoding strategies affect the quality of text generated by an LSTM-based language model.

---

# Dataset Download Instructions

## Dataset Source

The dataset used in this project consists of the complete Harry Potter book series in text format.  
It is publicly available on Kaggle.

Dataset Link:  
https://www.kaggle.com/datasets/shubhammaindola/harry-potter-books?resource=download

# Experiment 1: Baseline Model

**Objective**
- Establish a reference point for text generation performance
- Understand basic behavior of a simple LSTM model

**Configuration**
- Single LSTM layer
- Short, fixed sequence length
- No regularization
- Greedy decoding during generation

**Observations**
- Learned basic word ordering
- Frequent repetition in generated text
- Limited long-term context understanding
- Output quality degraded over longer sequences

**Conclusion**
- Suitable only as a baseline model
- Not sufficient for coherent long-form text generation

---

# Experiment 2: Deeper LSTM Architecture

**Objective**
- Improve grammatical structure and contextual learning

**Changes Made**
- Added an additional LSTM layer
- Increased model depth to learn complex language patterns

**Observations**
- Improved sentence flow and grammar
- Reduced repetition compared to baseline
- Better continuity across longer phrases
- Increased training complexity

**Conclusion**
- Deeper LSTM networks significantly enhance text coherence

---

# Experiment 3: Dropout Regularization

**Objective**
- Reduce overfitting and repetitive text generation

**Changes Made**
- Introduced dropout between LSTM layers

**Observations**
- Reduced memorization of frequent phrases
- Improved generalization to unseen text
- Increased diversity in generated output
- Slightly slower convergence

**Conclusion**
- Dropout regularization improves robustness and output quality

---

# Experiment 4: Temperature-Based Sampling

**Objective**
- Improve diversity and naturalness of generated text

**Changes Made**
- Replaced greedy decoding with probabilistic sampling
- Introduced temperature parameter for randomness control

**Observations**
- Low temperature produced safe but repetitive text
- Medium temperature balanced coherence and creativity
- High temperature increased diversity but reduced stability
- Significant reduction in repetitive loops

**Conclusion**
- Temperature-based sampling is essential for realistic text generation

---

# Overall Outcome

- Baseline model produced limited-quality text
- Deeper LSTM layers improved grammar and flow
- Dropout reduced overfitting and repetition
- Temperature sampling increased creativity and realism
- Best results achieved by combining all improvements

---

# Key Takeaways

- Model depth directly impacts language understanding
- Regularization is critical for preventing repetition
- Decoding strategy strongly influences output quality
- Combining architectural and inference improvements yields the best results
